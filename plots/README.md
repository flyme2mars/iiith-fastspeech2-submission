# plots/

Submission figures do not go here.

Loss curves: `Results/<Language>/training_loss.png` and `validation_loss.png` from `scripts/plot_losses.py`.

Variance adaptor: `Results/<Language>/variance_adaptor_plots/{duration,pitch,energy}/<sentence id>.png` from `scripts/plot_variance.py`.

The scripts exit if the log or the prediction file is missing. They do not write a blank plot.
